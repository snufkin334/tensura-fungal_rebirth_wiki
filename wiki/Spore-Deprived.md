# Spore Deprived

**Spore Deprived** is a harmful status effect added by Fungal Rebirth. It is applied to a [Myconid Sprout](Myconid-Sprout.md) that leaves the Ancient Forest, as part of the [Spore Deprivation](Spore-Deprivation.md) mechanic.

| | |
|---|---|
| **Effect ID** | `fungalrebirth:spore_deprivation` |
| **Type** | Harmful |
| **Color** | Faded moss green (`#6B7F3A`) |
| **Duration** | Infinite (while the conditions last) |
| **Level** | I (no level shown) |
| **Particles** | None |
| **Cure** | None (cannot be removed by Milk or Honey) |

---

## Effects

| Attribute | Change | Equivalent |
|---|---|---|
| Movement Speed | −45% | Slowness III |
| Block Break Speed | ×0.09 (9% of normal) | Mining Fatigue II |
| Attack Speed | −20% | Mining Fatigue II |
| Magicule Regeneration | ×0 (no natural regeneration) | — |

All four penalties come from this single effect, so only one icon is shown.

> **Note:** Tensura calculates natural Magicule regeneration using a regeneration multiplier attribute, which this effect sets to zero. The extra regeneration from **Sleep Mode** does not use that attribute, so it still works.

---

## Obtaining

The effect cannot be obtained from potions or commands made by the addon. It is applied and removed automatically by [Spore Deprivation](Spore-Deprivation.md):

| Applied when | Removed when |
|---|---|
| A [Myconid Sprout](Myconid-Sprout.md) is outside the Ancient Forest, alive, and not in Creative or Spectator mode | The player returns to the Ancient Forest, switches to Creative or Spectator, or is no longer a Myconid Sprout |
