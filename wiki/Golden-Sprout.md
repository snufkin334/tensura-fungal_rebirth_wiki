# Golden Sprout

The **Golden Sprout** is a decorative technical block added by Fungal Rebirth. It is a small golden mushroom that grows on top of the soil marked by the [Perennial Rebirth](Perennial-Rebirth.md) skill of the [Genesis Mycoseraph](Genesis-Mycoseraph.md).

|---|---|
| **Block ID** | `fungalrebirth:golden_sprout` |

| **Item form** | None |
| **Light level** | 6 |
| **Breakable** | No (in Survival) |
| **Map color** | Gold |
| **Sound** | Fungus |

## How It Appears

The Golden Sprout is placed and removed automatically by [Perennial Rebirth](Perennial-Rebirth.md):

| Event | Result |
|---|---|
| A soil block is marked | A Golden Sprout grows on top of it |
| The mark is moved to another block | The old sprout disappears and a new one grows on the new block |
| The mark is cancelled or used by a rebirth | The sprout disappears |
| The marked block is broken or is no longer soil | The sprout disappears without dropping anything |
| The sprout is removed in Creative while the mark is active | It grows back within 1 second |
