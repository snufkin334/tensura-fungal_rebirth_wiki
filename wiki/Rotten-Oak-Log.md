# Rotten Oak Log

The **Rotten Oak Log** is a block added by Fungal Rebirth. It is an old, decayed oak log found in the [Pile of Rotten Logs](Pile-of-Rotten-Logs.md) structures of the Ancient Forest, and a good source of [Cryptid Insectoid Pupa](Cryptid-Insectoid-Pupa.md).

| | |
|---|---|
| **Block ID** | `fungalrebirth:rotten_oak_log` |
| **Tool** | Axe |
| **Properties** | Same as Oak Log |
| **Rotation** | 3 axes (like any log) |
| **Flammable** | Yes |
| **Creative tab** | Natural Blocks |
| **Renewable** | No |

## Obtaining

The Rotten Oak Log generates naturally in the [Pile of Rotten Logs](Pile-of-Rotten-Logs.md). When a pile is placed in the world, each **oak log** in it has a **10%** chance of being replaced by a Rotten Oak Log, keeping the same orientation.

It can only be collected as an item with **Silk Touch**.

---

## Drops

| Tool | Drop | Chance |
|---|---|---|
| Silk Touch | Rotten Oak Log | 100% |
| Anything else | [Cryptid Insectoid Pupa](Cryptid-Insectoid-Pupa.md) | 25% |
| Anything else | Nothing | 75% |

When destroyed by an explosion, the block may drop nothing, following the usual explosion rules for blocks.

---

## Properties

The Rotten Oak Log copies all properties of the vanilla **Oak Log**: hardness, blast resistance, sound and map color. It is mined fastest with an **axe**.

| Fire property | Value |
|---|---|
| Flammability | 5 |
| Fire spread speed | 5 |

These are the same values as the vanilla wooden logs.
