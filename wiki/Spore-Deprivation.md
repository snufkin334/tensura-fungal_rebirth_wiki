# Spore Deprivation

**Spore Deprivation** is a racial mechanic of the [Myconid Sprout](Myconid-Sprout.md). The tiny sprout depends on the spores of the **Ancient Forest**: whenever it leaves its home biome, it withers and receives the [Spore Deprived](Spore-Deprived.md) effect.

| | |
|---|---|
| **Type** | Racial mechanic (drawback) |
| **Race** | [Myconid Sprout](Myconid-Sprout.md) only |
| **Effect applied** | [Spore Deprived](Spore-Deprived.md) |
| **Safe biome** | Ancient Forest (`tensura:ancient_forest`) |

## When It Applies

Every **0.5 seconds**, the game checks the player. The effect is applied when **all** of these are true:

| Condition | Details |
|---|---|
| Race | Your race is [Myconid Sprout](Myconid-Sprout.md) |
| Location | You are **outside** the `tensura:ancient_forest` biome. Any other dimension also counts as outside. |
| Game mode | Survival or Adventure (not Creative or Spectator) |
| State | You are alive |

---

## Effects

You receive [Spore Deprived](Spore-Deprived.md) with **infinite duration** and no particles:

| Effect | Value | Equivalent |
|---|---|---|
| Movement Speed | −45% | Slowness III |
| Mining Speed | 9% of normal | Mining Fatigue II |
| Attack Speed | −20% | Mining Fatigue II |
| Magicule Regeneration | None | — |

> **Note:** Only natural Magicule regeneration stops. The extra regeneration from Tensura's **Sleep Mode** still works.

---

## How to Remove It

| Method | Works? |
|---|---|
| Return to the Ancient Forest | Yes |
| Switch to Creative or Spectator mode | Yes |
| Evolve into [Cordyceptic Stalker](Cordyceptic-Stalker.md) | Yes, permanently |
| Milk or Honey Bottle | **No** |

---

## Notes

- This is why the Myconid Sprout spawns inside the Ancient Forest. See [Getting Started](Getting-Started.md).
- Starting with the [Cordyceptic Stalker](Cordyceptic-Stalker.md), no fungal race is affected by Spore Deprivation.
