# Perennial Rebirth (Effect)

**Perennial Rebirth** is a beneficial status effect added by Fungal Rebirth. It is a **visual indicator only**: it shows that a [Genesis Mycoseraph](Genesis-Mycoseraph.md) has an active soil mark from the [Perennial Rebirth](Perennial-Rebirth.md) skill.

| | |
|---|---|
| **Effect ID** | `fungalrebirth:perennial_rebirth` |
| **Type** | Beneficial |
| **Color** | Gold (`#E8A317`) |
| **Duration** | While the soil mark is valid |
| **Particles** | None |
| **Cure** | None (cannot be removed by Milk, Honey or a Totem of Undying) |

---

## Effects

The effect does **nothing by itself**. It only tells you that you are protected. The actual rebirth is handled by the [Perennial Rebirth](Perennial-Rebirth.md) skill, which also checks whether the marked block is still valid.

---

## When It Appears and Disappears

| Shown when | Removed when |
|---|---|
| You mark a soil block with [Perennial Rebirth](Perennial-Rebirth.md) | The mark is used by a rebirth |
| | The mark is cancelled (Shift + press, or changing dimension) |
| | The marked block is broken or is no longer soil |
